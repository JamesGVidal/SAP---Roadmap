03 / VISÃO PRÁTICA

Onde cada tecnologia entra?

O mesmo requisito pode envolver uma API standard, lógica no CAP ou uma extensão ABAP no SAP.

↔

HTTP

Protocolo que transporta requisições, headers, cookies e respostas.

GET · POST · PATCH
⌘

OData

Contrato para entidades, filtros, navegações, metadados e ações.

$metadata · $filter · $expand
◇

CAP + CDS

Modela e expõe serviços no back-end; adiciona regras e consome APIs remotas.

Node.js · TypeScript · .cds
▤

ABAP CDS + RAP

Modela e implementa serviços e extensões dentro da camada ABAP.

Eclipse ADT · Service Binding
04 / REFERÊNCIA RÁPIDA

OData V2 versus V4

Diferenças comuns de protocolo. Confirme sempre o comportamento no $metadata e na documentação da API utilizada.

ASSUNTOODATA V2 · COMUMODATA V4 · COMUM
Coleções JSONd.resultsvalue
Objeto individualdObjeto JSON
Contagem$inlinecount$count=true
MetadadosEDMX XMLCSDL XML / JSON*
OperaçõesFunction ImportAction / Function
Paginação__next / $skiptoken@odata.nextLink
AtualizaçãoMERGE / PATCH*PATCH

* Variações dependem do serviço e de sua implementação. Uma API V2 não se torna V4 automaticamente.
